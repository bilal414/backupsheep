# Concept A — The Sentinel Sheep

**Status: Selected direction**

## Idea

A calm, watchful sheep becomes the visual shorthand for BackupSheep's role: it quietly monitors a distributed flock of protected resources and helps the operator keep a known route back.

The concept combines the Guardian and Engineer archetypes. It must look capable at infrastructure scale while remaining memorable and approachable.

## Logo concept

Create a compact geometric sheep head or upper-body symbol using a small number of strong shapes.

Preferred construction ideas:

- rounded wool mass forming a protective outer silhouette;
- face or negative space forming a downward data path;
- one subtle circular/return gesture that can suggest backup history or recovery;
- symmetrical or near-symmetrical construction for stability;
- alert ears, neutral expression, grounded posture.

Avoid literal cloud icons, shields, padlocks, server racks, floppy disks, arrows wrapped around a database, and overly detailed wool.

The mark must work at 16 px before decorative detail is added.

## Mascot

The mascot is a more expressive extension of the logo, not the logo itself.

Character traits:

- observant;
- calm;
- prepared;
- competent;
- slightly dry sense of humor;
- never frantic.

Use mascot artwork for onboarding, documentation covers, empty states, release announcements, contributor material, and social graphics.

Do not use playful mascot poses on failure alerts, destructive confirmations, security warnings, or active restore screens.

## Visual world

Imagine the sheep watching a field made of infrastructure nodes rather than a literal farm. Resources can appear as restrained geometric forms connected by paths to storage destinations. The visual metaphor is a protected flock, but the execution remains technical and abstract.

Supporting motifs:

- orbit/path lines;
- grouped nodes;
- nested archive layers;
- small status lights;
- return paths;
- subtle wool-like scallop geometry used sparingly.

## Color direction

Use a dark ink/navy foundation, warm wool neutral, and a distinctive fresh green as the brand accent. Operational success, warning, and danger colors remain semantically separate from the brand accent.

The palette should feel warmer and more ownable than the current generic indigo/slate SaaS treatment without sacrificing dashboard legibility.

## Typography direction

Use a distinctive but restrained display sans for marketing headlines and the wordmark, paired with a highly legible interface sans for console and documentation.

The display face should feel engineered rather than futuristic. Avoid sci-fi, monospaced branding, bubbly rounded type, and aggressive condensed type.

## Applications

### GitHub

A bold standalone sheep symbol for the repository avatar, a wide README lockup, and a social preview featuring the mark plus “Own the way back.”

### Website

Large confident typography, generous dark/light contrast, small infrastructure diagrams, and mascot moments that support rather than dominate the product UI.

### Console

Keep the interface operational. Apply the brand through logo, semantic tokens, typography, focus states, selected navigation, empty states, and restrained illustrations—not decorative mascot repetition.

### Documentation

Use simplified line diagrams and a consistent visual grammar for Source → BackupSheep → Destination → Recovery.

## Why this direction wins

1. It makes the name an asset rather than something to hide.
2. It differentiates BackupSheep from generic shield/vault/cloud backup brands.
3. It supports an open-source community without looking hobby-only.
4. It can be extremely simple at product-icon scale and expressive at campaign scale.
5. It embodies “quietly vigilant” naturally.
6. It gives the brand long-term character beyond a single color palette.

## Risks and controls

**Risk: too cute.** Control with geometric construction, neutral expression, dark foundation, and limited mascot use in operational screens.

**Risk: too farm-like.** Keep environments abstract and infrastructural; avoid grass, barns, fences, pastoral landscapes, and rustic typography.

**Risk: security-company cliché.** Do not add shields or armor. Protection should be communicated by posture, system design, and messaging.

## Creative test

Every final asset should pass this question:

> Does this look like a serious infrastructure tool with a memorable sheep—or a sheep-themed product trying to look technical?

Only the first outcome is acceptable.
